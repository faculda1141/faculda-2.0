# Faculda+ 🚀

Plataforma educacional online completa com banco de dados em tempo real (Firebase Firestore), catálogo de cursos, sistema de progresso de alunos e painel administrativo.

---

### 🌐 **Acesse a Aplicação Online (Live App)**

👉 **[Clique aqui para abrir o Faculda+](https://ais-pre-ier6t7qrpkyk6gbspjguvl-772160824905.us-east1.run.app)**

---

## 🛠️ Tecnologias Utilizadas

- **Frontend:** React 18, TypeScript, Tailwind CSS, Lucide Icons, Motion
- **Backend / API:** Node.js (Express)
- **Banco de Dados em Tempo Real:** Firebase Firestore
- **Build & Dev:** Vite, ESBuild

---

## ⚡ Como Rodar Localmente

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git
   cd SEU_REPOSITORIO
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Acesse no navegador:**
   `http://localhost:3000`

---

## 🗄️ Configuração do Banco de Dados (Firestore)

As credenciais do Firestore já estão configuradas no arquivo `firebase-applet-config.json` e no suporte a variáveis de ambiente `.env` para sincronização em tempo real de alunos, cursos e matrículas.
